# 配套技能的检查样例

先写检查样例，再编写技能正文。以下内容用于检查路由与操作要求，不把文字匹配当作模型触发准确率。

## 应当使用

| 用户请求 | 必须读取 | 应有行为 |
|---|---|---|
| 给这个远程补丁增加一个安卓设备，保留原模拟器。 | 项目说明、实例管理源码 | 追加稳定索引，原实例调用原接口；配置不含公开设备地址。 |
| 安卓画面黑屏，排查共享纹理和解码。 | 逐行说明、画面与纹理源码 | 先区分未连接、未解码、互斥超时和远程未显示；运行现有检查程序。 |
| 软件升级后更新本补丁，顺便重新打包。 | 版本匹配源码、打包脚本、验证记录 | 先重新取证签名与摘要；不直接修改版本白名单后宣称兼容。 |
| 我正在通过远程聊天，请更新补丁。 | 安装约定、当前验证记录、续接记录 | 先完成候选修改与检查；核对是否已有补丁。首次加载也须说明断连风险，已有补丁不能免重启换版；未取得相应授权时不进入启用。 |
| 加载后过一会后台崩溃，故障在系统版本代理。 | 逐行说明、私有转储、代理检查 | 区分进程附加和线程附加，检查静态线程局部状态及入口栈帧；先在独立小栈线程中复现。 |
| 新设备有画面，但预览偏色、主页无效、横屏和上下切换不可用。 | 手机兼容说明、画面几何、官方按钮路径 | 核对截图和纹理的不同像素顺序、主页系统操作、角度与坐标；先做六色及四角检查，再做同设备双通道只读检查。 |
| 已加载旧版，现在从另一个目录加载修复版。 | 加载工具、启用约定 | 拒绝叠加第二套挂接，先把新候选验证完整，再说明重启会断连并等用户确认。 |
| 暂不重启，保留候选包，先把结论沉淀到文档和技能。 | 续接记录、验证记录、当前文档差异 | 更新已确认事实、候选证据和待验证项；保持原候选包及摘要，不启动加载、设备检查或授权窗口，不再次询问重启。 |
| 手机复测都正常，只有刚进来闪一下；刚进来指打开多开管理界面。 | 验证记录、续接记录、手机兼容说明 | 将本轮询问的五项记为用户实测通过；闪屏位置按用户澄清记录为打开多开管理界面，不猜测根因，不扩展为多指或长期稳定性通过，不触发重新加载。 |
| 不要求单文件，依赖写进说明，希望其他电脑简单配置，重启仍有效。 | 部署使用说明、配置路径、安装和打包脚本 | 交付相对配置和持久代理安装；检查独立自动加载、隔离安装及网络重连，不复制本机标识；安装文件与正式重启接入分别记录，不自动重启远程连接。 |

## 不应使用

| 用户请求 | 原因 |
|---|---|
| 手机怎么开启安卓调试？ | 普通设备使用，不涉及本仓库。 |
| 给游戏脚本增加一个自动领取任务。 | 另一个项目的游戏自动化，应使用对应项目技能。 |
| 比较几款远程软件的收费。 | 产品咨询，不涉及补丁实现、维护或验证。 |

## 本轮检查

- 正文路由包括接口调查、实现验证、安装恢复和文档维护，每条都写明具体读取位置。
- 已将“独立画面检查通过”和“手机通过官方中继显示并可操作”列为不同验证结果。
- 实际崩溃暴露了仅测首次加载的缺口；已补入小栈线程生命周期检查，并用旧库复现、新库通过的结果迭代技能注意项。
- 已把运行中的远程连接、共享纹理交接、跨模块字符串和本地设备标识列为高成本注意项。
- 手机反馈暴露了预览和正式画面并发、主页单独系统操作、竖屏关闭手势等缺口；新增对应正例，路由到几何与手机兼容说明，不把状态数字改动作为修复。
- 本次文档续接补入“用户明确暂不重启”正例；其路径是先读续接记录、更新文档与技能、运行文档及提交检查，不进入构建或正式加载流程。
- 路由复核发现旧正例仍写“优先免重启加载”，未区分首次加载与换版；已修正，并明确纯文档任务不进入代码变更的构建与加载流程。
- 用户对“刚进来”的澄清补为正例；复测结果与剩余现象分别记录，避免把闪屏位置误记成进入设备画面。
- 已用上述十个正例和三个反例人工核对说明范围；这是人工路径检查，不是跨模型触发测试。持久部署路由增加了分发说明、隔离安装和正式重启的不同证据要求，技能结构检查通过。
- 尚未做跨模型触发实验，也未测量与不使用技能时的工具调用差异；不将这些项目标为通过。
