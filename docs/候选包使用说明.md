# 第二修订候选包

此包用于验证五项手机反馈，尚不是稳定发行版。仅支持本机已核对的后台版本 4.46.0.4716。手机端继续使用官方程序及原中继。

用户当前决定为“暂不重启，保留候选包”，下述启用步骤暂不执行。本次文档整理不会覆盖已归档的第二修订包；包内说明仍对应原提交，当前安排及摘要以仓库《续接记录.md》为准。

## 包内内容

- version.dll（补丁库）和 patch_load.exe（内存加载程序）。
- config.example.json（配置示例）：只含程序路径和视频参数。
- source.zip（对应提交的源码包）、第三方许可及详细说明。
- manifest.json（文件摘要清单）：记录源码提交和其余文件的安全摘要。

不包含设备标识、本地配置、官方安装包、日志、转储或分析数据库；安卓调试桥及投屏组件仍使用本机已有程序。

## 当前电脑启用

源码目录的第二修订在 build/revision2/Release（候选构建目录），旁边的根目录指针指向当前源码仓库，继续读取原有本地配置。上次确认时正式后台加载旧候选，不能再加载第二份；以后启用前需重新核对实际状态。

需要先说明并取得用户授权，再重启后台并加载第二修订。重启会中断现有远程连接，可能重新枚举显示器。当前通过远程聊天时，不要仅为了测试命令自行重启。持久化安装仍未开放。

## 在其他目录使用候选包

解压到独立目录，把配置示例复制为 config.local.json（本地配置），核对本机程序路径。要求 scrcpy（安卓投屏组件）5.0.1，配套 avcodec（视频解码库）63 和 avutil（多媒体工具库）61。配置放在补丁库旁边；不要复制本机开发用的根目录指针。

先确认后台中没有旧补丁，再从管理员终端运行以下命令。它只加载库，不会重启；加载成功后还需检查私有日志是否记录挂接启用。

```powershell
./patch_load.exe ./version.dll
```

如果提示另一个同名库已经加载，应先停止尝试，按照已约定的断连窗口重启后台。不要换目录重复加载。

## 手机复测

重新打开模拟器入口，依次观察预览颜色、反复进入退出、返回主页和最近任务、横屏方向、工具栏上下滑动切换。普通滑动、四角点击及多指也要分别核对；本地协议断言不能替代这些操作。

停用需让当前后台正常退出，内存挂接不支持热卸载。本包未安装到官方程序目录。所有缓存、私有日志、备份和安卓临时服务文件均保留，由用户自行决定后续清理，不随包分发。
