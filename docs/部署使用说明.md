# 安卓接入补丁使用说明

这个包把本机安卓设备接到 UU（远程软件）的模拟器入口，手机继续使用官方客户端和中继。安装后补丁随后台启动加载，不需要每次运行注入程序，也不依赖开发者的源码目录。

目前只支持六十四位微软桌面系统，以及后台版本 4.46.0.4716 的指定构建。安装脚本和补丁都会核对三个官方组件的完整摘要；版本号相同而文件不同，也不会启用挂接。没有绑定本机账号、设备地址或安装盘符，其他电脑满足上述条件即可按相同步骤配置。

当前验证：第二修订的预览颜色、进入画面、三个导航按钮、横屏和上下切换已经过用户手机复测。本包新增的自动加载、配置迁移和网络重连通过独立检查；正式后台重启后的自动接入仍需单独确认。多开管理预览退回占位图的闪烁尚未解决，多指和长期运行仍缺少专项手机记录。

## 准备依赖

1. 安装 PowerShell 7（命令终端），下载地址：https://github.com/PowerShell/PowerShell/releases 。后面的命令在该终端中运行。
2. 下载 scrcpy（安卓投屏组件）5.0.1 的六十四位微软系统压缩包：https://github.com/Genymobile/scrcpy/releases/tag/v5.0.1 。完整解压到本包的 runtime/scrcpy（依赖目录）。里面应有 adb.exe（安卓调试桥）、两个调试桥配套库、scrcpy-server（安卓服务）、avcodec-63.dll（视频解码库）、avutil-61.dll（视频工具库）及其他配套库。也可以使用已有组件目录，在配置里填写路径。
3. 打开设备的安卓调试并完成授权。通过数据线连接的设备通常无需额外配置。网络设备还需打开其网络调试端口；安卓的无线配对设备应先完成配对。

依赖由使用者从上游取得，不包含在补丁压缩包中。不能混用其他主版本的服务和解码库。保留上游的许可证和配套文件。

## 填写配置

将 config.example.json（配置示例）复制为 config.local.json（本地配置）。默认路径对应上面的目录，通常只需处理网络设备列表。

```json
{
  "adb": "runtime/scrcpy/adb.exe",
  "scrcpy": "runtime/scrcpy",
  "connect": [],
  "fps": 30,
  "max_size": 1920,
  "bit_rate": 8000000
}
```

所有相对路径都以配置文件所在目录为起点，与终端当前目录无关；有中文、空格的目录也可以使用。绝对路径同样支持。

connect（网络重连列表）留空表示发现当前调试桥里已有的设备。使用网络设备时，在数组中填写实际的“地址:端口”，如 `["192.0.2.1:5555"]`（仅为示例地址，使用时替换）。后台会尝试连接尚未在线的这些设备，之后继续定期发现；调试桥服务重启导致连接丢失时也会重试。它不会代替设备端开启网络调试或完成配对，设备端口变化后需更新配置。

fps（帧率）、max_size（最长边）和 bit_rate（视频码率）可以先用默认值。设备地址与授权信息只在本机配置，不需要交给补丁开发者。

## 安装

以管理员身份打开上述终端，进入本包目录，运行：

```powershell
./install.ps1 -Action Install
```

默认被控端目录为 C:/Program Files/Netease/GameViewer/bin（官方后台目录）。装在其他位置时，加上 `-HostDirectory '实际后台目录'`（安装位置参数），该目录应包含 GameViewerServer.exe（官方后台程序）。

脚本先核对官方文件、同名库与依赖，再把补丁、配置和依赖复制到被控端目录：

```text
bin/（被控端目录）
  GameViewerServer.exe（官方后台）
  version.dll（补丁代理）
  uu-adb-patch/（补丁数据目录）
    config.local.json（安装后的配置）
    install.json（安装记录）
    runtime/（复制后的运行依赖）
    private/（运行后生成的日志和设备映射）
```

安装后的依赖路径会改成相对路径，可以把原解压目录移走。脚本不会复制原电脑的设备映射、日志或源码，也不会覆盖其他同名库。相同补丁重复安装不会覆盖已经安装的配置。

脚本不会停止或重启后台。已有后台继续使用原来的内存状态；请在能够接受断连时正常重启被控端或电脑，新补丁从下一次后台启动开始加载。之后只要官方后台正常启动，补丁就会一起加载；本包不另外创建开机任务或服务，也不负责启用官方软件自身的开机启动。

查安装文件状态可运行 `./install.ps1 -Action Status`（状态检查）；预演安装可加 `-WhatIf`（只检查而不复制）。这些文件检查不能证明运行中的进程已经加载。包内 startup_check.exe（独立自动加载检查）可以验证所在目录的代理是否由系统自动加载，也不等于正式后台已接入。

## 修改配置和查看结果

安装以后修改的是被控端目录下 uu-adb-patch/config.local.json（安装后的配置）。修改完成后，在可接受断连时正常重启后台；配置在启动时读取，不会热更新。解压目录里的配置只用于首次安装。

运行后查看 uu-adb-patch/private（本机运行记录目录）里的当前进程日志。出现“hooks active for host 4.46.0.4716”（匹配版本的挂接已启用）说明挂接完成；还要在手机端重新打开多开列表，检查实际显示和操作。若没有设备，先核对调试桥授权、网络端口及重连列表。不能仅凭安装成功判断手机连接正常。

## 停用和更新

停用运行 `./install.ps1 -Action Disable`（停用命令），必要时传入安装位置参数。脚本依据安装记录核对补丁摘要，将库改名保留，配置与依赖也保留；未知同名文件拒绝处理。当前进程中的补丁不会热卸载，后台下一次正常启动后停用。

更新补丁时，先停用，在约定的断连时间正常退出后台，再把旧的 uu-adb-patch（补丁数据目录）改名备份；使用新包和配置重新安装，之后正常启动。旧库和旧配置均不删除。正在运行的版本不能从其他路径叠加加载，后台或电脑重启前应保存正在进行的工作。

官方升级后若摘要不匹配，补丁会保留系统版本接口转发并拒绝挂接，不代表新版本已兼容。升级器也可能整理安装目录；升级后重新检查安装文件，等待适配相应官方构建。

本包不包含任何设备标识、凭据、官方安装包或私有诊断文件。所有备份、运行记录及安卓临时服务文件均保留，清理由使用者自行决定。
